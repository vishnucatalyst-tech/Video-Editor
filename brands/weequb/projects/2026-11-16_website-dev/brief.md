# Brief

**Brand:** Weequb Technologies (BRAND.md still has DEMO colours/fonts/logo — confirm before final)
**Topic / goal:** Promote Weequb's website development service → drive comments (lead keyword)
**Platform:** Instagram Reel, 1080x1920
**Audience:** Tamil Nadu small-business owners / shop owners with an old site or no site
**Target length:** ~22 s
**Language:** Tanglish (romanised Tamil + English) — VO and captions
**Hook (first 1.5 s):** "Unga website customers-ah miss pannudhu!" over a slow-loading site on a phone
**Key message:** Slow / non-mobile sites lose customers → Weequb builds fast, mobile-first, SEO-ready sites that bring enquiries
**CTA:** Comment "STORE" (free website audit)
**Structure:** pain hook → agitate (speed, mobile) → solution (Weequb) → proof (before/after) → CTA end card
**Pacing:** fast, visual change ≤ 3 s, punch-in on emphasis words
**Captions:** pop, upper case, accent colour on numbers / WEEQUB / STORE
**Music:** upbeat 100–128 BPM, licensed only, ducked −14 dB under VO
**Must avoid:** unverified claims ("3x enquiries") unless a real client result backs it

## Script (Tanglish)

| Time | Visual | On-screen caption | Voiceover |
|---|---|---|---|
| 0.0–1.5 | Phone close-up: site stuck loading, thumb tapping | **UNGA WEBSITE CUSTOMERS-AH MISS PANNUDHU!** | "Unga website customers-ah miss pannudhu!" |
| 1.5–4.0 | User gives up, swipes the site away | **3 SEC LOAD AANA… BYE BYE** | "3 seconds-ku mela load aana, aalunga poyiduvanga." |
| 4.0–7.0 | Broken mobile layout, tiny text, pinch-zoom | **MOBILE-LA SARI ILLAYA? GOOGLE-LA UM ILLA.** | "Mobile-la sariya varalana, Google-um kaata maataanga." |
| 7.0–9.0 | Hard cut → talking head, punch-in 1.1x | **KAVALAI VENAAM. WEEQUB IRUKKU!** | "Kavalai venaam — Weequb irukku!" |
| 9.0–15.0 | Before → After split, smooth scroll of new site, Lighthouse 95+ | **FAST · MOBILE-FIRST · SEO-READY** | "Fast-aa, mobile-first-aa, SEO-ready website — first day-lendhe." |
| 15.0–19.0 | WhatsApp / enquiry notifications popping | **VISITORS → ENQUIRIES** | "Visitors-ah customers-ah maathura website." |
| 19.0–22.0 | Clean end card, logo, no watermark | **COMMENT "STORE" 👇 FREE AUDIT** | "Free audit venumaa? 'STORE'-nu comment pannunga!" |
