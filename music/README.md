# Music library

Licensed tracks only, sorted into one folder per mood, for example:

```
music/
  upbeat/      100–128 BPM
  chill/
  cinematic/
  corporate/
```

- Keep the licence or receipt next to each track (`<track>.licence.pdf`, or a line in `LICENCES.md`).
- Brand-exclusive tracks go in `brands/<brand>/assets/music/`, never here. CLAUDE.md: never reuse another brand's music.
- Audio files are git-ignored. Back them up somewhere else.
